Role-Based Access Hierarchy (5 Tiers)

Governance matrix defining security boundaries across university personas

1. User

4,280 accounts. Report issues, track personal tickets, rate service.

2. HOD / Warden

48 accounts. Review and verify complaints within assigned jurisdiction.

3. Worker

95 accounts. Receive 30m dispatches, execute work, upload photo proof.

4. Facilities Admin

12 accounts. Manage workers, departments, override assignments.

5. Super Admin

3 accounts. Configure algorithm weights, audit logs, system settings.
